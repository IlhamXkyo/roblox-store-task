# roblox-store-task
🎮 Roblox Store - Sistem E-Commerce Item Roblox berbasis Web (PHP Native, MySQL, Bootstrap 5). Project UAS Pemrograman Web dengan fitur Autentikasi (Admin/Buyer), Katalog Produk, Keranjang, Tracking Status (Dikemas→Selesai), Ulasan &amp; Rating, serta Dashboard Admin (CRUD Kategori, Produk, Pelanggan, Pesanan).
